# Domain Context — article-search

## Glossary

- Excerpt — the short fragment of an Article (2–3 sentences) that best matches a Reader's search query, shown on a search result. NOT the beginning of the article or an editor-written teaser.
- Tag — a free-text label of one language that the Admin gives an Article (at least one per article; a rubric label found in the Word file is applied as one), compared ignoring letter case and extra spaces, never shown to Readers and used only to find «Similar articles». NOT the rubric heading printed in the paper (only its source), NOT a public category page, and NOT the issue number.
